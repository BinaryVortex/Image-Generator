# Image Generator

Image Generator built using HTML, CSS and JavaScript. A lightweight, client-side web app that allows you to compose or generate images through simple controls and preview them in the browser.

## Demo

![Image Generator Screenshot](./Screenshot%202024-08-22%20183519.png)

## Features

- Clean, responsive UI built with HTML and CSS
- Interactive JavaScript logic for generating/manipulating images
- No build tools or server required — runs entirely in the browser

## Quick start

1. Clone the repository:

   ```bash
   git clone https://github.com/BinaryVortex/Image-Generator.git
   cd Image-Generator
   ```

2. Open `index.html` in your browser (double-click the file or use `File -> Open`):

   - Or start a simple static server (recommended if the app loads assets via fetch):

     ```bash
     # Python 3
     python -m http.server 8000
     # Then open http://localhost:8000 in your browser
     ```

3. Use the UI controls to generate or edit images and download the result.
